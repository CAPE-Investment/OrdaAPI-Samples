# OrdaAPI 3.0 서비스 데이터 구조 정의

이 폴더는 서비스 데이터 구조 정의를 언어별로 관리합니다. 향후 C++, C#, Python, Delphi Sample 지원에 맞추어 확장할 예정이며, 현재는 C++ 구조체용 `cpp/` 폴더만 관리합니다.

## 언어별 폴더 규칙

`sdk/structs/<언어>/` 아래에 해당 언어의 서비스 데이터 구조 정의 파일을 둡니다. 서로 다른 언어의 정의는 각 언어 폴더에서 독립적으로 관리합니다.

| 언어 | 폴더 | 상태 |
| --- | --- | --- |
| C++ | `cpp/` | 현재 관리 대상 |
| C# | `csharp/` | 향후 지원 예정, 아직 생성하지 않음 |
| Python | `python/` | 향후 지원 예정, 아직 생성하지 않음 |
| Delphi | `delphi/` | 향후 지원 예정, 아직 생성하지 않음 |

현재 C++ 폴더에는 관리 규칙만 제공하며 실제 구조체 Header는 사용자가 직접 작성하여 추가합니다. 자세한 규칙은 [C++ README](cpp/README.md)를 참고합니다.
