# 옵션전광판 (t3043)

Visual Studio 2010에서 `OrdaAPI-t3043-OptionBoard.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다.

월물은 YYYYMM 6자리이며 기본값은 없습니다. 실제 상장 월물은 서버에서 확인합니다. 근월물·변동성 요약은 위에, 콜과 풋 목록은 아래 좌우에 배치했습니다. 두 목록은 독립적으로 수신하며 각각 최대 200건을 표시합니다. 행사가를 기준으로 병합하거나 정렬하지 않습니다.

최초 조회를 제공합니다. 반복 건수는 블록 수신 길이를 SDK 구조체 크기로 나누어 계산합니다. 가격, 수량, 변동성 및 민감도는 전문의 문자 표현을 유지합니다. 구체적인 단위와 서버의 허용 범위는 실조회에서 확인해야 합니다.

로컬 오프라인 검증은 `python tests/run-offline.py`로 실행합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
