# 시간대별투자자매매추이 (t2012)

Visual Studio 2010에서 `OrdaAPI-t2012-InvestorTrends.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

시장구분 1자리와 업종코드 3자리의 기본값은 각각 1과 001입니다. 조회건수 cnt는 4자리이고 기본값은 0020입니다. 서버에서 허용하는 시장·업종코드 조합 및 cnt 범위는 확인이 필요합니다. 수량·금액과 전일분은 코드표를 사용합니다. 고정 출력에 투자자별 합계, 반복 출력에 시간대별 순매수를 표시합니다. 요청 cts_time(8)과 cts_idx(4)는 공백입니다. 응답에는 cts_time만 있어 cts_idx의 출처 및 재전송 계약이 확인될 때까지 최초 조회를 제공합니다.

고정 출력은 위쪽 목록에, 반복 출력은 아래쪽 목록에 표시합니다. 수신 건수는 반복 블록 길이를 SDK 구조체 크기로 나누어 계산합니다. 화면에는 최대 200건을 표시하며 전문의 수치 표기를 유지합니다. 금액·수량의 실응답 단위와 소수점은 서버 확인 대상입니다.

이 폴더에서 `python tests/run-offline.py`를 실행하면 실제 SDK 헤더로 두 빌드를 수행하고 테스트 DLL로 동작을 검증합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
