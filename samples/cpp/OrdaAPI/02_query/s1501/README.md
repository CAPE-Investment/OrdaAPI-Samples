# ELW 현재가 호가조회 (s1501)

Visual Studio 2010에서 `OrdaAPI-s1501-ElwOrderBook.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 `sdk/bin`입니다.

ELW 단축코드는 6바이트입니다. 위쪽에 현재가와 기타 종목 정보, 아래쪽에 10단계 매도·매수 가격, 일반 잔량, LP 수량 및 잔량 증감을 표시합니다. 공백은 빈 셀로, 숫자 0은 서버가 보낸 문자로 표시합니다.

최초 조회를 제공합니다. 수치 표기는 전문의 문자를 유지합니다. 가격·수량의 단위와 유효한 업무 코드 범위는 실제 서버에서 확인합니다.

로컬 오프라인 검증은 `python tests/run-offline.py`로 실행합니다. 테스트 파일은 기존 Git 제외 규칙을 따릅니다.
