# 업종현재가 (t1253)

Visual Studio 2010에서 `OrdaAPI-t1253-IndustryQuote.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

업종코드는 숫자 3자리입니다. 전문에 기본 업종코드가 정의되어 있지 않아 입력란을 비워 둡니다.

반복 건수는 블록 바이트 길이를 SDK 구조체 크기로 나누어 계산합니다. 블록마다 최대 200건을 표시합니다. 숫자 필드는 전문의 부호와 소수점 표기를 유지합니다.

로컬 오프라인 검증은 이 폴더에서 `python tests/run-offline.py`로 실행합니다. 테스트는 기존 Git 제외 규칙이 적용되는 로컬 `tests/` 소스를 사용합니다.
