# 외국계매매상위 (t2091)

Visual Studio 2010에서 `OrdaAPI-t2091-ForeignBrokerRanking.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 시장·매매·수량금액 구분을 선택합니다.

고정 출력 없이 반복 블록 두 개를 받습니다. 두 블록 모두 종목 시세와 매도·매수 합계를 제공하며, XML은 각각의 `chad`와 `chas`를 모두 순매도로 설명합니다. 블록 설명 속성이 없어 탭을 순매도 (chad)와 순매도 (chas)로 표시합니다. 두 블록의 순위 방향과 실제 수치 단위는 서버 확인 대상입니다.

블록별 수신 건수는 각 블록의 바이트 길이를 구조체 크기로 나누어 계산합니다. 탭마다 최대 200건을 표시합니다. 전문에 본문 연속키가 없어 최초 조회를 제공합니다.

오프라인 검증은 이 폴더에서 `python tests/run-offline.py`로 실행합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
