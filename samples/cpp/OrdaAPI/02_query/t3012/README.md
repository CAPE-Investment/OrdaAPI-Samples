# 기간별주가 (t3012)

Visual Studio 2010에서 `OrdaAPI-t3012-FuturesHistoricalPrices.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다.

단축코드 8자리, 최근월물 적용 여부(CHECK), 날짜(공백 또는 YYYYMMDD), 요청건수 3자리(기본값 020)를 사용합니다. 최초 요청의 cts_code와 전종목만기일 lastdate는 각 8바이트 공백입니다. date·cts_code·lastdate는 요청과 응답에 같은 길이로 존재합니다. 최근월물 변경 시 어떤 조건에서 이 세 필드를 재전송하는지 확인되지 않아 최초 조회만 제공합니다. 상세 시세는 서버 수신 순서대로 표시합니다.

최초 조회를 제공합니다. 반복 건수는 블록 수신 길이를 SDK 구조체 크기로 나누어 계산합니다. 가격, 수량, 변동성 및 민감도는 전문의 문자 표현을 유지합니다. 구체적인 단위와 서버의 허용 범위는 실조회에서 확인해야 합니다.

로컬 오프라인 검증은 `python tests/run-offline.py`로 실행합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
