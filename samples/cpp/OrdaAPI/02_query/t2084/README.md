# 회원사매매수신 (t2084)

Visual Studio 2010에서 `OrdaAPI-t2084-BrokerTrading.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

회원사코드 3자리, 종목코드 6자리, 그룹코드 4자리입니다. 기본값은 000, 공백, 공백입니다. 순매수/순매도 값과 요청건수는 숫자 12자리와 3자리이며 기본값은 000000000000과 020입니다. 요청 연속키 cts_tradtime(8), cts_idx(4), cts_shcode(6)는 공백입니다. 응답 고정 블록에는 시간과 인덱스만 있으며 반복 블록의 shcode를 다음 키로 쓰는 계약이 확인되지 않아 최초 조회만 제공합니다.

고정 출력은 위쪽 목록에, 반복 출력은 아래쪽 목록에 표시합니다. 수신 건수는 반복 블록 길이를 SDK 구조체 크기로 나누어 계산합니다. 화면에는 최대 200건을 표시하며 전문의 수치 표기를 유지합니다. 금액·수량의 실응답 단위와 소수점은 서버 확인 대상입니다.

이 폴더에서 `python tests/run-offline.py`를 실행하면 실제 SDK 헤더로 두 빌드를 수행하고 테스트 DLL로 동작을 검증합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
