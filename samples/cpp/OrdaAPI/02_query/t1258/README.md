# 업종별종목시세 (t1258)

Visual Studio 2010에서 `OrdaAPI-t1258-IndustryStocks.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

기본 조건은 업종코드 001, 구분 1(코스피), 거래소 3(통합)입니다. 구분은 1 코스피, 2 코스닥, 3 섹터를 선택할 수 있습니다. 각 구분에서 허용되는 업종코드와 선택 종목코드 조합은 서버에서 확인해야 합니다. 처음 조회할 때 ContiKey 4바이트는 공백입니다. 다음 조회는 헤더의 연속 플래그와 응답 ContiKey를 사용합니다.

반복 건수는 블록 바이트 길이를 SDK 구조체 크기로 나누어 계산합니다. 블록마다 최대 200건을 표시합니다. 숫자 필드는 전문의 부호와 소수점 표기를 유지합니다.

로컬 오프라인 검증은 이 폴더에서 `python tests/run-offline.py`로 실행합니다. 테스트는 기존 Git 제외 규칙이 적용되는 로컬 `tests/` 소스를 사용합니다.
