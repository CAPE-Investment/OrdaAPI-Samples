# 증거금율별종목조회 (t1107)

Visual Studio 2010에서 OrdaAPI-t1107-MarginStocks.sln을 열고 Debug 또는 Release Win32로 빌드합니다. 디버거 작업 디렉터리는 저장소의 sdk/bin입니다. EXE를 직접 실행할 때도 sdk/bin을 작업 디렉터리로 지정합니다.

접속 서버를 선택하고 로그인한 뒤 조회 조건을 설정합니다. 처음 조회는 XML 기본값의 idx를 사용합니다. 다음 조회는 A형 헤더의 연속 플래그가 켜져 있고 응답 idx가 유효할 때 활성화됩니다. 조건을 바꾸면 처음 조회부터 시작합니다.

t1107OutBlock은 기본 정보와 idx를 제공하며, t1107OutBlock1의 반복 건수는 블록 바이트 길이를 구조체 크기로 나누어 계산합니다. 수신 건수와 ListView 표시 건수를 각각 표시하며 페이지당 최대 200건을 표시합니다. 출력 값은 전문의 문자 단위와 소수점 표기를 유지합니다.
