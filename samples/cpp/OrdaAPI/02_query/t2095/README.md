# 거래원별 매매상위 (t2095)

Visual Studio 2010에서 `OrdaAPI-t2095-BrokerTradingRanking.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

거래원코드는 3자리입니다. 시장과 순매수·순매도는 코드표에서 선택합니다. 최신 XML과 헤더의 요청·응답 next는 모두 NEXTKEY 4바이트입니다. 최초 조회에는 공백을 보내고 다음 조회는 A형 응답 헤더의 연속 플래그와 본문 next를 사용합니다. 마지막 페이지의 키 표기는 실제 서버 확인 대상입니다.

고정 출력은 위쪽 목록에, 반복 출력은 아래쪽 목록에 표시합니다. 수신 건수는 반복 블록 길이를 SDK 구조체 크기로 나누어 계산합니다. 화면에는 최대 200건을 표시하며 전문의 수치 표기를 유지합니다. 금액·수량의 실응답 단위와 소수점은 서버 확인 대상입니다.

이 폴더에서 `python tests/run-offline.py`를 실행하면 실제 SDK 헤더로 두 빌드를 수행하고 테스트 DLL로 동작을 검증합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
