# OrdaAPI Query 서비스 Sample Index

전체 SERVICE 109개의 XML Header Type과 Sample 상태입니다. A 65 / B 32 / C 6 / D 6이며 공통 코드표 codes.xml은 서비스가 아닙니다. Header Type과 별도로 XML의 attr·block·반복·연속 계약을 확인해야 합니다.

t1001은 사용자 개발서버 검증 완료입니다. 신규 b8024·d7304·d8311·t3084는 Debug/Release 빌드·오프라인 계약 검증 및 Runtime/GUI 초기화 확인까지 완료했으며 실제 서버 Login/Query는 미검증입니다. 나머지 104개는 예정입니다.

[Header Type 분석·검증 보고서](../../../../docs/query-header-type-samples-report.md), [전체 XML 필드 분석](../../../../docs/query-xml-structure-analysis.md), [공통 Helper](../common/README.md), [공통 코드표](../../../../sdk/bin/sys/codes.xml)를 참고하십시오. 공통 Helper와 기존 t1001 Source는 변경하지 않았습니다.

아직 구현하지 않은 서비스 Directory와 Generator는 생성하지 않았습니다. quote와 execution의 기존 계획 Directory는 유지했습니다.
