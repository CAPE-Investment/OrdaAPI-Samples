# 시간별예상체결가 (t1212)

Visual Studio 2010에서 OrdaAPI-t1212-ExpectedExecutions.sln을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 sdk/bin입니다.

접속 서버를 선택하고 로그인한 뒤 조회 조건을 설정합니다. 응답 헤더의 연속조회 플래그와 고정 블록의 cts_time가 유효하면 다음 조회가 활성화됩니다. 이미 사용한 키가 돌아오거나 조건을 바꾸면 연속조회가 종료됩니다.

반복 건수는 t1212OutBlock1 바이트 길이를 SDK 구조체 크기로 나누어 계산합니다. ListView에 페이지당 최대 200건을 표시하며 전문의 숫자 표기를 유지합니다.
