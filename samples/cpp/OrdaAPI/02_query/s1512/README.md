# ELW 현재가 조회 (s1512)

Visual Studio 2010에서 `OrdaAPI-s1512-ElwQuote.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 `sdk/bin`입니다.

ELW 단축코드는 6바이트입니다. 탭은 ELW 종목·시세(83필드), ELW 호가·LP(103필드), 기초자산 시세(9필드), 추가 호가(86필드)입니다. 마지막 블록은 호가·종목코드·상하한가를 제공하며 그 적용 대상은 실응답에서 확인합니다. 네 블록 모두 고정 출력이고 순서와 무관하게 처리합니다. t1501은 고정 ELW 시세와 기초자산 반복 출력으로 구성됩니다.

최초 조회를 제공합니다. 수치 표기는 전문의 문자를 유지합니다. 가격·수량의 단위와 유효한 업무 코드 범위는 실제 서버에서 확인합니다.

로컬 오프라인 검증은 `python tests/run-offline.py`로 실행합니다. 테스트 파일은 기존 Git 제외 규칙을 따릅니다.
