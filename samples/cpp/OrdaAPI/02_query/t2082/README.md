# 종목별 상위회원사 (t2082)

Visual Studio 2010에서 `OrdaAPI-t2082-TopStockBrokers.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

조회날짜1과 조회날짜2에 시작일과 종료일을 YYYYMMDD로 입력합니다. 외국계구분은 CHECK의 0 미적용과 1 적용을 사용합니다. 최초 cts_idx는 공백 4바이트이며 다음 조회에 응답 cts_idx를 전달합니다.

고정 출력은 위쪽 목록에, 반복 출력은 아래쪽 목록에 표시합니다. 수신 건수는 반복 블록 길이를 SDK 구조체 크기로 나누어 계산합니다. 화면에는 최대 200건을 표시하며 전문의 수치 표기를 유지합니다. 금액·수량의 실응답 단위와 소수점은 서버 확인 대상입니다.

이 폴더에서 `python tests/run-offline.py`를 실행하면 실제 SDK 헤더로 두 빌드를 수행하고 테스트 DLL로 동작을 검증합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
