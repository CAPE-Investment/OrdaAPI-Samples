# 미결제약정분석 (t3053)

Visual Studio 2010에서 `OrdaAPI-t3053-OpenInterest.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다.

단축코드는 8자리입니다. T3053의 1(0.1), 2(0.2), 3(0.5), 4(1.0) 중 구간을 선택합니다. 기본값 3은 2바이트 termgbn에 뒤 공백을 채웁니다. 선물 전용 가격 범위의 기본값은 000000이며 양의 십진수 또는 0을 소수점 포함 6바이트 이내로 입력합니다. 문자열이 짧으면 오른쪽을 공백으로 채웁니다. 두 값이 모두 0이 아닐 때 시작가와 종료가 순서를 검사합니다. 옵션은 가격 범위 기본값을 사용합니다. 서버의 소수 자릿수와 패딩 허용 여부는 실조회에서 확인해야 합니다.

최초 조회를 제공합니다. 반복 건수는 블록 수신 길이를 SDK 구조체 크기로 나누어 계산합니다. 가격, 수량, 변동성 및 민감도는 전문의 문자 표현을 유지합니다. 구체적인 단위와 서버의 허용 범위는 실조회에서 확인해야 합니다.

로컬 오프라인 검증은 `python tests/run-offline.py`로 실행합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
