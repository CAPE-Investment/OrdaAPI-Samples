# 주식선물 현재가 조회 (s3009)

Visual Studio 2010에서 [OrdaAPI-s3009-StockFuturesQuote.sln](OrdaAPI-s3009-StockFuturesQuote.sln)을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 sdk/bin입니다. 기존 Common이 SDK DLL 로딩과 접속·로그인을 담당합니다.

Header Type A, block 1, attr 1입니다. 입력은 s3009InBlock입니다. SDK의 4인자 최초 조회 호출을 사용합니다.

| 출력 | occurs | 처리 |
|---|---|---|
| s3009OutBlock | 미지정 | 고정 구조체 1개 |

focode는 8바이트 선물 단축코드입니다. t3001의 focode와 필드명·길이·속성 바이트 배치가 일치합니다. 기존 t3001 샘플과 같이 영문 대문자 및 숫자 8자를 입력하며 선행 0을 유지합니다. s2105에서 조회하는 10바이트 기초자산코드는 별개입니다. 서버에서 유효한 선물 단축코드를 확인하십시오.

시세 표는 현재가, 전일대비·등락률, 시가·고가·저가, 미결제약정, 기준가·이론가, 기초자산과 가격제한을 포함한 고정 출력 72필드를 표시합니다. 호가는 기초자산의 매수·매도 호가 두 필드입니다. s3010은 같은 서비스명이지만 shcode 8바이트를 받고 선물의 매도·매수 10단 호가를 제공합니다. s3009에는 본문 연속키가 없습니다.

모든 수신값은 실제 SDK 구조체에서 고정 폭 문자열로 읽으며 단위를 변환하지 않습니다.

오프라인 테스트는 Python 3으로 tests/run-offline.py를 실행합니다. 버전 100 도구로 Debug·Release를 빌드하고 격리된 fake DLL과 WinAPI 메시지 테스트를 실행합니다. tests 디렉터리에는 기존 Git 제외 규칙이 적용됩니다.
