# 종목별 프로그램매매 추이 (t2052)

Visual Studio 2010에서 `OrdaAPI-t2052-StockProgramTrading.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

시간별·일별, 금액·수량, 거래소를 선택하고 종목코드 6자리를 입력합니다. 날짜 YYYYMMDD와 시간 HHMMSS의 기본값은 각각 공백입니다. 조회 모드별 날짜·시간 필수 조합은 서버 확인 대상입니다. 신규 조회의 cts_idx 4바이트는 공백입니다. 다음 페이지는 날짜·시간 등 기존 조건을 유지하고, 헤더 연속 플래그와 응답 cts_idx를 사용합니다. XML의 9999는 차트용 표시이므로 신규 조회의 기본값으로 사용하지 않습니다.

고정 출력은 위쪽 목록에, 반복 출력은 아래쪽 목록에 표시합니다. 수신 건수는 반복 블록 길이를 SDK 구조체 크기로 나누어 계산합니다. 화면에는 최대 200건을 표시하며 전문의 수치 표기를 유지합니다. 금액·수량의 실응답 단위와 소수점은 서버 확인 대상입니다.

이 폴더에서 `python tests/run-offline.py`를 실행하면 실제 SDK 헤더로 두 빌드를 수행하고 테스트 DLL로 동작을 검증합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
