# 국내외금융시장동향 (t1222)

Visual Studio 2010에서 `OrdaAPI-t1222-MarketTrends.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

탭은 국내 지수, 해외 지수, 환율, 투자주체, 증시 수치입니다. XML에 블록 설명 속성이 없어 블록별 필드 설명을 바탕으로 이름을 정했습니다. 각 탭에 수신 건수와 표시 건수가 따로 표시됩니다.

반복 건수는 블록 바이트 길이를 SDK 구조체 크기로 나누어 계산합니다. 블록마다 최대 200건을 표시합니다. 숫자 필드는 전문의 부호와 소수점 표기를 유지합니다.

로컬 오프라인 검증은 이 폴더에서 `python tests/run-offline.py`로 실행합니다. 테스트는 기존 Git 제외 규칙이 적용되는 로컬 `tests/` 소스를 사용합니다.
