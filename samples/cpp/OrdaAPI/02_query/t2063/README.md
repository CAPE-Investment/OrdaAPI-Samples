# 외인기관 종목별동향 (t2063)

Visual Studio 2010에서 `OrdaAPI-t2063-InvestorStockTrends.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

최신 XML의 todt 설명은 시작일자입니다. YYYYMMDD로 입력하고 연속조회에서도 유지합니다. 금액·수량·평균단가와 매수·매도는 코드표에서 선택합니다. 누적구분의 기본값은 공백이며 코드표가 없어 확인된 값만 직접 입력합니다. cts_date(8)와 cts_idx(4)는 처음에 각각 공백이며 응답의 두 필드를 다음 요청에 전달합니다.

고정 출력은 위쪽 목록에, 반복 출력은 아래쪽 목록에 표시합니다. 수신 건수는 반복 블록 길이를 SDK 구조체 크기로 나누어 계산합니다. 화면에는 최대 200건을 표시하며 전문의 수치 표기를 유지합니다. 금액·수량의 실응답 단위와 소수점은 서버 확인 대상입니다.

이 폴더에서 `python tests/run-offline.py`를 실행하면 실제 SDK 헤더로 두 빌드를 수행하고 테스트 DLL로 동작을 검증합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
