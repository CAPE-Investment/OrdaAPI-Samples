# ETF LP호가 (s1509)

Visual Studio 2010에서 `OrdaAPI-s1509-EtfLpQuotes.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 `sdk/bin`입니다.

ETF 단축코드는 6바이트입니다. 현재가 등 6개 시세 필드와 10단계 LP 매도·매수 수량을 표시합니다. 전문에는 단계별 가격이 없으며 공백과 0은 응답에 나타난 그대로 표시합니다. LP 호가 부재 시 서버가 사용하는 실제 표기는 실조회 확인 대상입니다.

최초 조회를 제공합니다. 수치 표기는 전문의 문자를 유지합니다. 가격·수량의 단위와 유효한 업무 코드 범위는 실제 서버에서 확인합니다.

로컬 오프라인 검증은 `python tests/run-offline.py`로 실행합니다. 테스트 파일은 기존 Git 제외 규칙을 따릅니다.
