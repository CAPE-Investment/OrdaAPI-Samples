# 주식챠트(종합) (s4100)

Visual Studio 2010에서 [OrdaAPI-s4100-StockChart.sln](OrdaAPI-s4100-StockChart.sln)을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 sdk/bin입니다. 기존 Common이 SDK DLL 로딩과 접속·로그인을 담당합니다.

Header Type A, block 1, attr 1입니다. 입력은 s4100InBlock입니다. SDK의 4인자 최초 조회 호출을 사용합니다.

| 출력 | occurs | 처리 |
|---|---|---|
| s4100OutBlock | 미지정 | 고정 구조체 1개 |
| s4100OutBlock1 | 1 | 블록 수신 길이 ÷ 구조체 크기 |

BlockName으로 각각 처리하며 블록 도착 순서와 무관합니다. 화면의 차트 목록은 200건까지 표시하고 수신 건수는 별도 집계합니다.

주식 단축코드는 6바이트입니다. 고정 표는 당일·전일 시세, 상하한가 및 연속키를 표시합니다. 반복 표는 일자·시간·OHLC·거래량·거래대금·수정주가 관련 필드를 포함합니다. s4101과 달리 가격은 8바이트이며 미결제약정 필드는 없습니다.

gubun은 주기구분, tdgb는 당일구분이며 각각 1바이트입니다. XML에 값 또는 coderef가 없고 codes.xml의 CHART_TIME·CHART_DWM은 값이 서로 달라 이 서비스에 대응하는 표를 확정할 수 없습니다. 두 구분값은 확인한 코드가 있을 때 직접 입력합니다. ncnt(틱개수)와 qrycnt(건수)는 숫자 문자 최대 4바이트입니다. 실제 허용 범위나 서버 최대 건수는 확인되지 않았으며 200건 표시 제한은 요청에 적용하지 않습니다. 날짜 입력은 선택이며 YYYYMMDD의 달력 날짜와 시작·종료 순서를 검사합니다. XML에 입력 기본값이 없어 비어 있는 조건과 속성 바이트를 공백으로 전송합니다. 주기에 따른 필수 조건과 서버 유효값은 실조회에서 확인하십시오.

cts_date(8), cts_time(10), cts_daygb(1)은 입력과 고정 출력에 모두 있습니다. 최초 조회는 해당 필드를 공백으로 초기화합니다. 제품의 Type A 헤더는 다섯 번째 인자의 포인터 유무로 연속 플래그를 설정합니다. 이 서비스의 복합키 재전달 조건과 응답 szPNFlag 관계를 뒷받침하는 계약을 확인할 수 없어 최초 조회만 제공합니다.

모든 수신값은 실제 SDK 구조체에서 고정 폭 문자열로 읽으며 단위를 변환하지 않습니다.

오프라인 테스트는 Python 3으로 tests/run-offline.py를 실행합니다. 버전 100 도구로 Debug·Release를 빌드하고 격리된 fake DLL과 WinAPI 메시지 테스트를 실행합니다. tests 디렉터리에는 기존 Git 제외 규칙이 적용됩니다.
