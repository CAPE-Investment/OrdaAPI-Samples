# 신용거래동향 (t1361)

Visual Studio 2010에서 `OrdaAPI-t1361-CreditTrends.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

종목코드와 융자·대주 구분을 선택합니다. 신규 조회 날짜는 YYYYMMDD 또는 공백이며 idx는 공백입니다. 다음 조회에서는 입력 날짜 대신 응답의 date와 idx를 함께 보냅니다. 고정 블록의 cnt는 화면에 표시하며 반복 건수는 반복 블록 길이로 계산합니다.

반복 건수는 블록 바이트 길이를 SDK 구조체 크기로 나누어 계산합니다. 블록마다 최대 200건을 표시합니다. 숫자 필드는 전문의 부호와 소수점 표기를 유지합니다.

로컬 오프라인 검증은 이 폴더에서 `python tests/run-offline.py`로 실행합니다. 테스트는 기존 Git 제외 규칙이 적용되는 로컬 `tests/` 소스를 사용합니다.
