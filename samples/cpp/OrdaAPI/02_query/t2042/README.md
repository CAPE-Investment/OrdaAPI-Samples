# 시간대별 프로그램매매추이 (t2042)

Visual Studio 2010에서 `OrdaAPI-t2042-ProgramTrading.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다. 접속 서버를 선택하고 로그인한 뒤 조회합니다.

시장·금액수량·직전대비·전일 구분의 기본값은 모두 0입니다. 날짜 YYYYMMDD와 시간 HHMMSS는 각각 공백이 기본값입니다. 응답은 날짜CTS(8), 시간CTS(6), IDX(4)를 제공하며 요청에 IDX가 없습니다. 날짜·시간 재사용만으로 다음 페이지를 얻는 계약이 확인될 때까지 최초 조회를 제공합니다. t2047은 투자자코드를 추가로 받고 거래량도 반환하며 직전대비 기본값이 공백입니다.

고정 출력은 위쪽 목록에, 반복 출력은 아래쪽 목록에 표시합니다. 수신 건수는 반복 블록 길이를 SDK 구조체 크기로 나누어 계산합니다. 화면에는 최대 200건을 표시하며 전문의 수치 표기를 유지합니다. 금액·수량의 실응답 단위와 소수점은 서버 확인 대상입니다.

이 폴더에서 `python tests/run-offline.py`를 실행하면 실제 SDK 헤더로 두 빌드를 수행하고 테스트 DLL로 동작을 검증합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
