# 선물/옵션 현재가 (t3001)

Visual Studio 2010에서 `OrdaAPI-t3001-FuturesOptionsQuote.sln`을 열고 Debug 또는 Release Win32로 빌드합니다. 실행 작업 디렉터리는 저장소의 `sdk/bin`입니다.

선물과 옵션 단축코드 모두 영문 대문자 및 숫자 8자리로 입력합니다. s3001은 shcode 8바이트와 고정 5단 호가를 사용합니다. t3001은 focode 8바이트와 58필드 단일 반복 블록을 사용합니다. 현재가 필드는 t3001이 6바이트, s3001이 10바이트입니다.

최초 조회를 제공합니다. 반복 건수는 블록 수신 길이를 SDK 구조체 크기로 나누어 계산합니다. 가격, 수량, 변동성 및 민감도는 전문의 문자 표현을 유지합니다. 구체적인 단위와 서버의 허용 범위는 실조회에서 확인해야 합니다.

로컬 오프라인 검증은 `python tests/run-offline.py`로 실행합니다. 테스트 소스에는 기존 Git 제외 규칙이 적용됩니다.
